## 🔧 How It Works

```
User Opens App
    ↓
Check localStorage for login
    ↓
├─ Logged in → Load role → Show correct tabs
│
└─ Not logged in → Show login page
                    ↓
                   Choose role
                    ↓
                   Enter credentials
                    ↓
                   API authenticates
                    ↓
                   Save token & role
                    ↓
                   Initialize app
                    ↓
                   Show role-specific tabs
```
