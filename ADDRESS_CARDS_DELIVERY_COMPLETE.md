## 🎯 How Admins Use It

### Access
1. Admin Dashboard → Sidebar → "Address Cards" menu
2. OR Sales Report → "View Address Cards" button
3. OR Direct URL: `/admin-address-card.html`

### Basic Usage
1. **View**: All customer addresses appear as cards
2. **Search**: Type name/email/phone to filter
3. **Print**: Click "Print" on card or "Print All"
4. **Copy**: Click "Copy" to clipboard
5. **Export**: Click "Export CSV" to download

### Advanced Usage
- Batch print multiple addresses
- Export to Excel for bulk processing
- Search for specific customers
- Copy for system integration
- Organize by reference number
