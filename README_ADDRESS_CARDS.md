# 📍 ADDRESS CARDS - ADMIN FEATURE

## Quick Overview

Admins can now **view, search, filter, and print customer shipping addresses** from all completed orders in one professional interface.

---

## 🚀 Start Using It Now

### Access the Feature
1. Log in as Admin
2. Go to Admin Dashboard
3. Click **"Address Cards"** in the sidebar (System section)
4. OR click **"View Address Cards"** button from Sales Report page

### What You See
- Customer addresses displayed as professional cards
- Search box to find specific customers
- Statistics showing total orders
- Action buttons to print or copy

### What You Can Do
- 🔍 **Search** by customer name, email, or phone
- 🖨️ **Print** individual or all addresses
- 📋 **Copy** address to clipboard
- 📊 **Export** as CSV for bulk processing

---

## ⚡ 60-Second Tutorial

```
1. Open Address Cards page
   → See all customer addresses
   
2. Type a name in search box
   → Results filter instantly
   
3. Choose an action:
   
   OPTION A: Print One
   → Click "Print" on card
   → Send to printer
   
   OPTION B: Print All
   → Click "Print All" button
   → Multi-page document
   
   OPTION C: Copy
   → Click "Copy" on card
   → Paste in your system
   
   OPTION D: Export
   → Click "Export CSV"
   → Open in Excel
```

## 🎯 Common Tasks

### Print a Single Address
1. Search for customer (optional)
2. Find their card
3. Click "Print" button
4. Select printer
5. Click Print

**Result**: One address card printed

### Print Multiple Addresses
1. Click "Print All" at the top
2. Select printer
3. Click Print

**Result**: All addresses printed on multiple pages

### Find a Specific Customer
1. Type their name in search box
2. Results filter in real-time
3. Click their card
4. Take action (print/copy)

### Copy Address to Another System
1. Find customer
2. Click "Copy" button
3. Go to other system
4. Paste (Ctrl+V)

**Result**: Address pasted into clipboard

### Export All Data
1. Click "Export CSV" button
2. File downloads: `address-cards-DATE.csv`
3. Open in Excel
4. Process bulk data
