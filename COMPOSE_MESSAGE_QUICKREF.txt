╔════════════════════════════════════════════════════════════════════╗
║                      QUICK START GUIDE                             ║
╚════════════════════════════════════════════════════════════════════╝

FOR ADMIN USERS:
───────────────

1. Open http://localhost:5000/admin.html
2. Click "Messages" in sidebar menu
3. Click "Compose Message" button
4. Select manager from "To:" dropdown
5. Enter subject line
6. Type message in textarea
7. (Optional) Select priority level
8. Click "Send Message"
9. See: ✅ "Message sent successfully!"
10. Message appears in your Sent messages
11. Manager receives message in their Inbox


FOR MANAGER USERS:
──────────────────

1. Open http://localhost:5000/admin_complain.html
2. Click "Messages" tab
3. Click "Compose Message" button
4. Select admin from "To:" dropdown
5. Enter subject line
6. Type message in textarea
7. (Optional) Select priority level
8. Click "Send Message"
9. See: ✅ "Message sent successfully!"
10. Message appears in your Sent messages
11. Admin receives message in their Inbox

INPUT VALIDATION:
─────────────────

⚠️  "Please select a recipient"
    → Shown if To: field is empty
    → Click dropdown and select from list

⚠️  "Please enter a subject"
    → Shown if Subject field is empty
    → Enter at least 1 character

⚠️  "Please enter a message"
    → Shown if Message textarea is empty
    → Enter at least 1 character

✅ "Message sent successfully!"
    → Shown when message is sent successfully
    → Modal closes automatically
    → Message list refreshes

❌ "Error: [Error Message from Server]"
    → Shown if server returns error
    → Check recipient is valid
    → Try again

╔════════════════════════════════════════════════════════════════════╗
║                      FORM FIELD DETAILS                            ║
╚════════════════════════════════════════════════════════════════════╝

TO (RECIPIENT):
───────────────
• Type: Dropdown Select
• Required: YES
• Source: Auto-loaded from /api/users/staff
• Admin sees: All Manager accounts
• Manager sees: All Admin accounts
• Display format: "Name (email@example.com)"


SUBJECT:
────────
• Type: Text Input
• Required: YES
• Max length: 500 characters
• Placeholder: "Message subject..."
• Min length: 1 character


MESSAGE:
────────
• Type: Textarea
• Required: YES
• Height: 150px minimum (resizable)
• Placeholder: "Type your message here..."
• Min length: 1 character
• Supports: Multiline text


PRIORITY:
─────────
• Type: Dropdown
• Required: NO (defaults to "Normal")
• Options:
    - Low
    - Normal (default)
    - High
• Affects: Badge color in message list

╔════════════════════════════════════════════════════════════════════╗
║                    HOW IT WORKS (TECHNICAL)                        ║
╚════════════════════════════════════════════════════════════════════╝

WORKFLOW:
─────────

[User clicks "Compose Message"]
         ↓
[openXxxComposeModal() function called]
         ↓
[Fetch managers/admins from /api/users/staff]
         ↓
[Create modal HTML dynamically]
         ↓
[Inject modal into DOM]
         ↓
[Add submit event listener to form]
         ↓
[User fills form]
         ↓
[User clicks "Send Message"]
         ↓
[submitXxxMessage() function called]
         ↓
[Validate all fields]
         ↓
[Send POST request to /api/messages]
         ↓
[Response received from server]
         ↓
[If success: Show ✅, close modal, refresh list]
[If error: Show ❌, keep modal open, show error]


API ENDPOINT USED:
──────────────────

POST /api/messages

Request Body:
{
  "recipientId": "user_id_string",
  "subject": "Message subject",
  "body": "Message content",
  "priority": "normal|high|low"
}

Response (Success):
{
  "success": true,
  "message": "Message sent successfully",
  "messageId": "message_id_string"
}

Response (Error):
{
  "success": false,
  "message": "Error description"
}
