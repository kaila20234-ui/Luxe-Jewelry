Support & Troubleshooting
❓ First Time Setup? Start by creating an admin account using the "Create Admin Account" button above. This will allow you to log in and manage other users.
🔐 Authentication The system uses role-based access control. Admins have full system control, while managers handle customer interactions like complaints and support tickets.
💬 Messaging System Admins and managers can communicate securely using the built-in messaging system. Navigate to Messages in the dashboard to send and receive messages.
⚙️ Settings & Configuration After creating an admin account, access the admin dashboard to configure system settings, manage users, and customize your store.
📊 Database & Backups The system uses MongoDB to store all data. Ensure your database is properly configured and regularly backed up in production.
🚨 Troubleshooting If you encounter issues:
  • Check that MongoDB is running and accessible
  • Verify environment variables are properly configured
  • Check browser console for error messages
  • Clear localStorage and try logging in again
  • Ensure you're using the correct credentials (email/username)
