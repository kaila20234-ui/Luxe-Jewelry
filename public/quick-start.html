Important Notes

✅ Authentication
All staff pages require login with admin or manager role. You'll be automatically redirected to login if not authenticated.
⚠️ Messaging Restrictions
Admins can only message managers, and managers can only message admins. Same-role communication is not allowed.
✅ First Admin Account
Use init-admin.html to create the first admin account. This endpoint only works if no admin exists yet.
⚠️ Password Security
Always use strong passwords (minimum 6 characters). Passwords are securely hashed using bcrypt before storing in the database.
✅ Session Persistence
Your authentication is automatically stored in browser localStorage. You'll remain logged in until you explicitly logout.

Troubleshooting

How do I create the first admin?
Visit http://localhost:5000/init-admin.html and fill in your admin details. This page only works if no admin account exists yet.
Can managers message other managers?
No, the system is designed for cross-role communication only. Managers can message admins, and admins can message managers. Same-role messaging is blocked for organizational clarity.
What if I forgot my admin password?
You'll need to either:
1. Reset via database directly if you have access
2. Have another admin create a new account for you
3. Contact your database administrator
How do I see all messages in a conversation?
Click on any message in the Inbox or Sent tab. The message detail view will show the full conversation thread with all related messages.
Can I delete messages?
Yes! In the message detail view, you'll see a "Delete" button. You can also "Archive" messages to hide them without permanently deleting.
How are messages auto-sorted?
Messages are sorted by newest first. Unread messages are highlighted with a pink background. You can mark them as read by clicking the message, and they'll automatically update.
