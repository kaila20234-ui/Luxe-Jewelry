# 🎁 Customer Address Cards - Quick Start

## What's New?
Admins can now **view and print customer shipping addresses** from all completed purchases in a professional card format.

## 🚀 How to Access

### From Admin Dashboard:
```
Admin Dashboard (sidebar)
    ↓
System Section
    ↓
📍 Address Cards ← CLICK HERE
```

### From Sales Report:
```
Sales Report Page
    ↓
🟢 "View Address Cards" Button
    ↓
Address Cards Page Opens
```

---

## 📋 What You Can Do

### 1️⃣ View Addresses
- See all customer shipping addresses in card format
- Shows: Name, Phone, Email, Full Address, Order #, Amount, Date

### 2️⃣ Search Customers
```
Search Box → Type customer name, email, or phone
    ↓
Results filter in real-time
    ↓
Find exactly who you need
```

### 3️⃣ Print Options

**Option A: Print One Card**
```
Card → Click "Print" Button → Select Printer → Print
```

**Option B: Print All Cards**
```
Top Button "Print All" → Select Printer → Multi-page print
```

**For Thermal/Label Printers**: Print individual cards
**For Regular Printers**: Use "Print All" for batch printing

### 4️⃣ Copy Address
```
Card → Click "Copy" Button
    ↓
Address copied to clipboard
    ↓
Paste into shipping system/Excel
```

### 5️⃣ Export as CSV
```
"Export CSV" Button → Download file
    ↓
Open in Excel/Google Sheets
    ↓
Process bulk orders offline
```

## 💡 Example Use Cases

### Scenario 1: Print Shipping Labels
1. Go to Address Cards
2. Click individual customer
3. Click "Print"
4. Print to label printer
5. Done! Label ready for package

### Scenario 2: Prepare Multiple Shipments
1. Go to Address Cards
2. Click "Print All"
3. Print all addresses
4. Sort by reference number
5. Prepare shipments in order

### Scenario 3: Find Specific Customer
1. Go to Address Cards
2. Type customer name in search
3. Click their card
4. Copy address
5. Update shipping system

### Scenario 4: Bulk Data Export
1. Go to Address Cards
2. Click "Export CSV"
3. Download spreadsheet
4. Import into shipping software
5. Process bulk orders
